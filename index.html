はじめての方向け:基本の使い方

1
投稿する
「投稿」タブに画像をドラッグ&ドロップ →「投稿する」を押すだけ。プロンプトや設定は画像から自動入力されます。「編集用パスワード」を設定しておくと、あとから自分で投稿を編集できます。
2
見る
「画像投稿一覧」でみんなの作品をチェック。クリックで詳細が開き、プロンプトはコピーボタンでそのまま使えます。
3
探す
一覧上部の「並び順」チップと「絞り込み」欄、タグクリックで目当ての作品を検索できます。パネル表示にすると右上のスライダーで表示サイズを調整できます。プロンプトそのものを探したいときは「プロンプトデータバンク」タブが便利です。
4
リアクションする
気に入った作品にはグッドボタンを押せます。コメントで感想を伝えることもできます。詳細画面からは画像のダウンロードや、共有URLのコピーができます。
ここまでできれば十分に使えます。以下は「もっと使いこなしたい人向け」の全機能の説明です。気になったところだけ読んでください。

このツールでできること

Stable Diffusionなどで生成した画像と、そのプロンプトや生成設定を記録・共有し、仲間内で情報交換するためのボードです。ログインもアカウント登録も不要で、ブラウザだけで使えます。投稿には次の種類があります。
画像投稿
生成した画像に、プロンプト・生成設定・タグ・メモを付けて共有します。「画像投稿一覧」タブに並びます。
動画投稿
生成した動画を、画像投稿と同じようにプロンプト・タグ・ジャンル等を付けて共有します。「動画投稿一覧」タブに並びます。長い動画は投稿に失敗することがあります。
プロンプト例の投稿
自分で考えたオリジナルキャラやシチュエーションのプロンプトを、画像なしで1つの「作品」として共有します。「プロンプト投稿一覧」タブに並びます。
リクエストの投稿
「こういう画像を作ってほしい」という依頼を出せます。参考資料の画像も添付できます。「リクエスト一覧」タブに並びます。
修正依頼の投稿
すでにある画像に対して「ここをこう直してほしい」という依頼を出せます。「修正依頼一覧」タブに並びます。
投稿どうしは「紐づけ」でつながります。たとえば画像を投稿するときに「ベースにしたプロンプト例」を選んでおくと、そのプロンプト例の詳細を開いたときに、それをベースに作られた画像作品が一覧で表示されます。プロンプト例をタグのように使って作品を探せる、ということです。

タブごとにできること

投稿
作品や依頼を投稿するタブです。上部のボタンで「画像を投稿」「プロンプト例を投稿」「リクエストを投稿」「修正依頼を投稿」を切り替えます。
画像投稿一覧
投稿された画像作品が並びます。リスト表示とパネル表示を切り替えられ、並び順・絞り込み・キーワード検索・タグで探せます。
動画投稿一覧
投稿された動画作品が並びます。サムネイルの▶印が目印で、開くとその場で再生できます。
プロンプト投稿一覧
画像なしのプロンプト例が並びます。画像一覧とほぼ同じ探し方ができます(リスト表示のみ)。
リクエスト一覧
「こういう画像が見たい」という依頼が並びます。誰かが応えて投稿すると、その依頼の詳細に作品がまとまって表示されます。
修正依頼一覧
「この画像のここを直してほしい」という依頼が並びます。対応した作品は依頼の詳細にまとまって表示されます。
プロンプトデータバンク
みんなの投稿に実際に使われているプロンプト語を集計し、日本語訳つきの辞書にしたタブです。使いたい語をカートに集めてまとめてコピーできます。
掲示板
作品に紐づかない雑談・質問の場です。スレッドを立てて、各スレッドに返信していく形式で、並び順の切り替え(投稿順・最新の返信がある順・勢い順)や画像の添付もできます。
更新
ヘッダー右上の「更新」ボタンを押すと、ページを再読み込みせずに新しい投稿などを取り込みます。ログイン画面を出している場合でも、再ログイン（再認証）は不要で、その場ですぐ最新の状態になります。他の人の新着を見たいときに、ブラウザの再読み込みの代わりに使ってください。
お知らせ
運営からのお知らせがあるときは、タイトル直下に未読のお知らせが1件ずつ縦に並んで表示されます（画面が埋まらないよう、ここに常時出るのは新しい3件までです）。各行の「既読」ボタンを押すまで消えないので、見落としません。行をクリックすると、そのお知らせの全文モーダルが開きます（画像が添付されていれば一緒に表示）。ヘッダー右上の「お知らせ」ボタンを押すと、これまでのお知らせをタイトルと投稿日時の一覧で確認でき、項目をクリックすると全文を読み返せます。既読にするのは各行の「既読」ボタンから行います。
本ツールの使い方
このページです。いちばん下に管理者への連絡フォームがあります。
はじめてガイド
自分のパソコンで画像生成を始めるまでの手順(ソフトの導入・モデルの入手・初回生成)をまとめた別記事です。

投稿するときに使える機能

画像の生成情報を自動で読み取る
ドロップゾーンに画像を入れると、Stable Diffusion系のツールが画像に埋め込んだ生成情報(PNGのparameters、JPEG/WebPのUserComment)を読み取り、プロンプト・ネガティブプロンプト・生成設定をフォームへ自動入力します。生成情報に「UI Preset」が含まれていないときは、Checkpoint名から自動で判定して補完します(例: 名前に xl を含めば xl、flux なら flux のように、投稿ツールのUI Presetと同じ表記が入ります)。読み取れた内容は投稿前に手で直せます。
プレビューの拡大と取り消し
アップロードした画像はフォーム上に大きくプレビューされます。クリックで全画面表示、右上の ✕ でアップロードの取り消しができます。
生成設定の入力
UI Preset / Checkpoint / VAE / Sampling Method / Steps / Width / Height / CFG Scale / Seed など、生成設定を項目ごとに記録できます。各入力欄の右端にある ▼ を押すと、これまでの投稿で使われた値が一覧で出るので、そこから選ぶだけで入力できます(手入力もできます)。
タグ
既存のタグはクリックで付け外しでき、新しいタグは入力欄から追加できます。タグは画像投稿とプロンプト例で共通のプールなので、みんなが使っている言葉に合わせると探しやすくなります。タグは必須です。1つも選ばずに投稿しようとすると、投稿できずに「タグを1つ以上選択してください」と表示されます(修正依頼の投稿でも同じです)。
投稿者名
任意入力です。空欄のまま投稿すると「匿名」と表示されます。
メモ(備考)
「この設定だと手が崩れやすい」「LoRAはこれを併用」など、プロンプト以外の補足を自由に書けます。
リクエストの参考資料
リクエストを投稿するときは、参考にしてほしい画像を複数枚まとめて添付できます。添付欄の「＋追加」タイルを押すか、そこへドラッグ&ドロップで追加でき、送信前に自動で縮小されます。サムネイルはクリックで拡大、右上の ✕ で削除できます。
編集用パスワード
画像投稿・プロンプト例・リクエストのどのフォームにも「編集用パスワード(任意)」欄があります。ここにパスワードを設定して投稿すると、あとから自分でその投稿を編集できるようになります(空欄のままでも投稿は可能です)。パスワードは投稿後には変更できず、詳細画面には設定済みかどうかだけが表示されるので、パスワードそのものが他の利用者に見えることはありません。
差分を同時に投稿
同じ設定でSeed違いを量産したときなど、複数枚の画像を1つの投稿にまとめてアップロードできます。投稿フォーム右上の「差分を同時に投稿」を押すと、画像欄の下に差分画像を追加する枠が出ます。最初にアップした画像が ［1］（メイン）、追加した画像が ［2］［3］… になります。サムネイル列には ［1］（メイン画像）も並ぶので、［1］［2］［3］を同じ感覚でクリックして切り替えられ、その画像の詳細設定（プロンプト・ネガティブ・生成設定）をフォームに呼び出して個別に確認・修正できます（各画像の生成情報は自動で読み取られます）。閲覧するときは、詳細画面の画像の下に出る 1・2… のボタンで切り替えられ、プロンプトや設定も画像ごとに切り替わります。似た作品で一覧があふれるのを避けたいときは、こちらか「親にする投稿作品」による親子紐づけのどちらかを使ってください。投稿後に編集するときも、差分をまとめた投稿なら［1］［2］［3］すべてのページのプロンプト・設定を編集できます（差分を追加・削除することもできます）。
修正後画像モード
画像の一部だけを描き直した(inpaint した)ときなど、「元画像の生成情報はそのまま残しつつ、投稿する画像は修正後のものにしたい」場合に使います。投稿フォーム右上の「修正後画像モード」を押すと、上に「投稿する画像(修正後)」のアップロード欄、その下に「元画像から情報だけ読み込む」欄が出ます。上のアップロード欄に修正後の画像を入れるとその画像だけがアップロードされ、下の読み込み欄に元画像を入れるとプロンプト・ネガティブ・生成設定だけがフォームへ反映されます(こちらの画像は投稿されません)。読み取った情報は投稿前に手で直すこともできます。

投稿どうしを紐づける

投稿フォームの下の方にあるピッカー(選択ボタン)から、他の投稿と関連づけられます。紐づけておくと、お互いの詳細画面から行き来できるようになります。
ベースにしたプロンプト例(画像 → プロンプト例・複数選択可)
「このプロンプト例を参考に作りました」という関係です。プロンプト例の詳細の下に、それをベースにした画像作品が一覧表示されます。
親にする投稿作品(画像 → 画像・1件のみ)
同じ設定でSeed違いを量産したときに使います。親を指定した作品(子)は一覧に並ばず、親の詳細の下に「この作品のバリエーション」としてまとまります。一覧が似た作品であふれるのを防ぐための仕組みです。
参考にした投稿作品(画像 → 画像・1件のみ)
「この作品を参考にして作りました」という関係です。投稿フォームの「参考作品を選択」から選びます。親子紐づけと違って子作品にはならないので、あなたの投稿はこれまでどおり画像投稿一覧に表示されます。指定すると、詳細画面に「参考にした投稿作品」へのリンクが出て、元の作品をすぐ開けます。
応えるリクエスト(画像 → リクエスト・1件のみ)
「このリクエストに応えて作りました」という関係です。リクエストの詳細の下に、応えた作品が一覧表示されます。
対応する修正依頼(画像 → 修正依頼・複数選択可)
「この修正依頼に対応して作りました」という関係です。修正依頼の詳細の下に、対応作品が一覧表示されます。
選んだ相手はフォーム上にタグのようなチップで表示されます。間違えたときはチップを外して選び直してください。紐づけはすべて任意で、何も選ばずに投稿しても構いません。

一覧から作品を探す

並び順
一覧の上部にあるチップで、日時・グッド数・ダウンロード数・投稿者・UI Preset・Checkpoint などの順に並べ替えられます。同じチップをもう一度押すと昇順/降順が入れ替わり、複数のチップを押すと押した順に優先されます。
絞り込み
投稿者・UI Preset・Checkpoint を部分一致で絞り込めます。右端の「絞り込みをクリア」で条件をまとめて解除できます。
キーワード検索
タイトル・プロンプト・ネガティブプロンプト・メモをまとめて検索します。スペース区切りで複数の語を指定でき、AND(すべて含む)/OR(どれかを含む)/NOT(どれも含まない)を切り替えられます。
タグで絞込
タグはクリックでON/OFF。こちらも AND / OR / NOT を切り替えられます。タグクラウドは1行だけ表示されますが、右端の「全て表示」で全タグの一覧を開けます。選んだタグは必ず先頭に並ぶので、1行に収まらなくても見失いません。
リスト表示 / パネル表示
画像投稿一覧では表示形式を切り替えられます。パネル表示は画像を元の縦横比のまま敷き詰める形式で、隣の「表示サイズ」スライダーで大きさを調整できます。
子も全て表示
通常は隠れているバリエーション(親に紐づいた子作品)も、このボタンを押すと一覧にすべて表示されます。
修正依頼作品も表示
通常は画像投稿一覧に並ばない修正依頼の投稿も、このボタンを押すと一緒に表示されます。
回答済み・対応済みで絞る
リクエスト一覧・修正依頼一覧の並び順チップの末尾には3段階のチップがあり、押すたびに「全件 → 応えられたものだけ → まだ応えられていないものだけ」と切り替わります。まだ誰も応えていない依頼を探すときに便利です。
先頭に戻る
画面右下のボタンでページの先頭へ戻れます。詳細画面を開いているときは、その詳細画面の先頭へ戻ります。

詳細画面でできること

一覧の作品をクリックすると詳細画面が開きます。閉じるときは右上の「✕ 閉じる」、背景のクリック、または Esc キーです。
プロンプトのコピー
PROMPT / NEGATIVE PROMPT それぞれの「コピー」ボタンで、そのまま自分の生成ツールに貼り付けられます。
ダウンロード
画像を原寸で保存できます。
画像の切り替え(差分投稿)
複数枚をまとめた投稿では、画像のすぐ下の左側に番号ボタン(1・2…)が四角で並びます。押すと表示する画像が切り替わり、PROMPT / NEGATIVE / 設定関係も画像ごとに切り替わります(1 が最初に投稿された画像です)。ダウンロードは、そのとき表示している画像が対象になります。
共有
その作品を直接開けるURLをコピーできます。リンクを送られた人は、開いた瞬間にその作品の詳細が表示されます。管理者に投稿について連絡するときも、このURLを添えると確実です。
グッド
気に入った作品に付けられます。1つの投稿につき同じ端末・ブラウザから1回まで、もう一度押すと取り消せます。
バッド
ふさわしくないと感じた投稿に付けられます。グッドと同じく1端末1回で、もう一度押すと取り消せます。バッドが一定数に達した投稿は自動的に一覧から見えなくなります。
コメント
「コメント N件」を押すとコメント画面が開きます。上のフォームから名前(任意)とメッセージを書いて投稿でき、下に投稿済みのコメントが並びます。
編集(自分の投稿)
投稿時に「編集用パスワード」を設定した作品は、詳細画面右上の「編集」ボタンから、そのパスワードを入力して自分で内容を修正できます。
紐づいた投稿へのジャンプ
「ベースにしたプロンプト例」「応えたリクエスト」「対応した修正依頼」のリンクや、詳細の下に並ぶバリエーション・関連作品をクリックすると、そのまま相手の詳細へ移動できます。閉じれば元の一覧に戻ります。

プロンプトデータバンクの使い方

「プロンプトデータバンク」タブは、みんなの投稿で実際に使われているプロンプトを「,」ごとに分解して集計し、日本語訳つきの一覧にした辞書です。「こういう表現、英語で何て書くんだろう？」を探すのに便利です。
絞り込む・並べ替える
「ソース」(PROMPT / NEGATIVE)や「対象」(画像投稿 / プロンプト例)を切り替え、「並び順」(採用回数順 / 英語名順 / 日本語名順)で整列できます。絞り込み欄は英語・日本語・ジャンル・キーワードのどれでも部分一致で探せます。
使用作品を見る
各プロンプトのカードをクリックすると、そのプロンプトを使っている作品が一覧で開きます。作品をクリックすれば詳細へ移動できます。
カートでまとめてコピー
「カートに入れるモード」をオンにして使いたいプロンプトをクリックすると、カートに追加されていきます。「COPY」でまとめてコピーでき(A, B, C の形式)、そのまま自分の画像生成に貼り付けられます。チップの ✕ で個別削除、「カートを空にする」で全消去できます。
日本語訳は自動翻訳をベースに管理者が整えています。訳が「—」の語は、少し待つと自動で埋まります。カートの中身はページを読み込み直すと消えるので、必要な分をコピーしてから閉じてください。

修正依頼の使い方

依頼する
「投稿」タブの「修正依頼を投稿」から、直してほしい画像と「修正依頼の具体的な内容」を書いて投稿します。入力できる項目は画像投稿と同じです。
依頼を探す
投稿した依頼は「修正依頼一覧」タブに並びます。「対応済み」チップで、まだ誰も応えていない依頼だけを表示できます。
依頼に応える
直した画像を投稿するときに「対応する修正依頼」でその依頼を選ぶと紐づき、依頼の詳細に対応作品としてまとめて表示されます。
修正依頼の投稿は、通常は画像投稿一覧には並びません。一覧上部の「修正依頼作品も表示」を押すと一緒に表示できます。

掲示板の使い方

特定の作品に紐づかない話題(雑談・質問など)はこちらへどうぞ。上のフォームから新しいスレッドを立て、各スレッドに返信していく形式です。お名前は任意で、空欄なら「匿名」と表示されます。
スレッドと返信
上のフォームで投稿するとスレッド(親)ができます。各スレッドの「返信する」ボタンから、そのスレッドにぶら下がる返信を書けます(返信にも画像を添付できます)。返信は投稿の古い順に並びます。既存の返信は最初は折りたたまれていて、「返信を表示 ▾」を押すと開きます。
並び替え
スレッドの並び順を「投稿順(新しいスレッドが上)」「最新の返信がある順」「勢い順(返信の多さと経過時間から算出)」で切り替えられます。
画像の添付
スレッドにも返信にも画像を複数枚まとめて添付できます。添付欄の「＋追加」タイルを押すか、そこへドラッグ&ドロップするだけでOK。送信前に自動で縮小されるので、大きな画像でもそのまま入れて大丈夫です。追加した画像はクリックで拡大、右上の ✕ で削除できます。
グッド / バッド
各スレッドに 👍 / 👎 を付けられます。1端末につき1票で、押し直せば取り消しや切り替えができます。
投稿の削除は管理者のみが行えます。スレッドを削除すると、そのスレッドへの返信もまとめて削除されます。取り消したい書き込みがある場合は、このページ下部の連絡フォームからお知らせください。

よくある質問(Q&A)

サイトを開くとパスワードの入力を求められます。
管理者がログイン画面をオンにしている場合、サイトを開いた最初に合言葉(パスワード)の入力を求められます。仲間内だけで使うための簡単な入場制限です。パスワードが分からない・入場できない場合は、管理者に確認してください。一度正しく入力すると、その端末では次回以降は自動で入場します(管理者がパスワードを変更すると再入力が必要になります)。認証を通すまでは投稿などの中身はサーバーから一切返されないため、URLを直接開いても中身は見えません。なお、サーバー(GAS)に接続できないときは「接続できません。再接続しています...」と表示され、接続が回復するまで自動で待ち続けます(この間は中身は表示されません)。
投稿した作品(画像・プロンプト例)は削除できますか？
投稿者自身による削除機能はありません。削除は管理者のみが対応できるため、消したい投稿がある場合は管理者へ削除依頼を出してください。依頼の際は、どの投稿かが分かるようにタイトルや共有URLを添えてもらえると確実です。
個人情報が管理者や第三者にバレませんか？
バレません。本ツールはGoogleアカウントでのログインを一切要求せず、投稿も閲覧もすべて匿名のリクエストとして処理されます。管理者側に届く(スプレッドシートに記録される)のは、あなたがフォームに入力した内容と画像そのものだけで、IPアドレスやアカウント情報を管理者が知る手段は仕組み上ありません。他の利用者に対しても同様で、投稿者名は任意入力・空欄なら「匿名」と表示されるだけです。ただし、投稿者名・タイトル・メモ・プロンプトに自分で本名や連絡先などを書けば、それは管理者にも他の閲覧者にも見えます。また画像のメタデータ(生成情報)に個人的な情報が含まれる場合があるため、気になる場合は投稿前に内容を確認してください。
画像投稿とプロンプト例の投稿は何が違いますか？
画像投稿は「生成した画像そのもの」を共有する機能です。プロンプト例の投稿は「自分で考えたプロンプト」を作品として共有する機能で、画像は添付しません。画像を投稿するときに、参考にしたプロンプト例を「ベース」として紐づけられます。
プロンプト例をベースにした画像は、どうやって探しますか？
「プロンプト投稿一覧」でプロンプト例を開くと、その例をベースにして投稿された画像作品が、詳細の下に一覧で表示されます。逆に画像の詳細を開いたときは「ベースにしたプロンプト例」からその例へジャンプできます。
同じ設定で生成した画像が何枚もあります。全部投稿してもいいですか？
はい。ただし一覧が同じような作品であふれないように「親子紐づけ」を使ってください。まず1枚を普通に投稿し、2枚目以降は画像投稿フォームの「親にする投稿作品」でその作品を選んで投稿します。子になった作品は画像投稿一覧には表示されず、親の詳細を開くと「この作品のバリエーション」として下に一覧表示され、クリックで詳細を見られます。なお、一覧上部の「子も全て表示」を押すと、子の作品も含めてすべてを一覧(パネル表示を含む)に表示できます。
画像をドロップしたらプロンプトや設定が勝手に入りました。なぜですか？
Stable Diffusion系のツールが画像に埋め込む生成情報(PNGのparametersやJPEG/WebPのUserComment)を自動で読み取り、フォームに反映しています。内容は手動で修正してから投稿できます。
画像をドロップしても何も自動入力されません。
画像に生成情報が埋め込まれていない場合(SNSやチャットアプリを経由した画像、加工・変換した画像、生成情報を保存しない設定で出力した画像など)は読み取れません。その場合は各項目を手入力してください。入力欄の右端の ▼ を押すと、これまでの投稿で使われた値から選べます。
投稿した内容は後から編集できますか？
投稿後の編集機能はありません。内容を直したい場合は、投稿し直すか、管理者へ相談してください。投稿するときに「編集用パスワード」を設定しておくと、詳細画面右上の「編集」ボタンからそのパスワードを入力して、後から自分で内容を修正できます。パスワードを設定しなかった投稿や、パスワードを忘れてしまった投稿は編集できないため、その場合は投稿し直すか、管理者へ相談してください。
リクエストと修正依頼・プロンプト例は、どう使い分ければいいですか？
「まだ存在しない画像を作ってほしい」ときはリクエスト、「すでにある画像のここを直してほしい」ときは修正依頼です。プロンプト例は依頼ではなく、自分の書いたプロンプトを共有する投稿です。
投稿したリクエストに誰かが応えてくれたか、どこで分かりますか？
リクエストの詳細を開くと、いちばん下に「このリクエストに応えて投稿された作品」が一覧表示されます。一覧の行にも回答作品の件数が出るので、そこでも確認できます。
キーワード検索の AND / OR / NOT はどう使いますか？
検索欄にスペース区切りで複数の語を入れたときの扱い方の指定です。ANDは入力した語をすべて含む投稿、ORはどれか1つでも含む投稿、NOTはどれも含まない投稿を表示します。タグの絞り込みでも同じ3種類を選べます。
タグクラウドに目当てのタグが見当たりません。
タグは1行だけ表示され、あふれた分は隠れています。行の右端にある「全て表示」を押すと全タグの一覧が開きます。選んだタグは常に先頭に移動するので、選択中のタグが隠れてしまうことはありません。
プロンプトデータバンクの日本語訳が「—」だったり、意味が変だったりします。
日本語訳は自動翻訳をもとに用意しており、新しく使われた語は少し時間をおくと自動で埋まります(「—」は未登録の状態です)。訳が不自然な語や、もっと良い訳・関連キーワードを足したい場合は、管理者が辞書を直接直せます。気になる訳があれば使い方タブ下部の連絡フォームから管理者へ知らせてください。
生成した画像を直してほしいときは？
投稿タブの「修正依頼を投稿」から、直してほしい画像と「修正依頼の具体的な内容」を書いて投稿してください。投稿した依頼は「修正依頼一覧」タブに並びます。依頼に応えるときは、画像を投稿する際に「対応する修正依頼」でその依頼を選ぶと紐づき、依頼の詳細ページに対応作品としてまとめて表示されます。なお修正依頼の投稿は画像投稿一覧には並びません(一覧上部の「修正依頼作品も表示」を押すと一緒に表示できます)。
「グッド」は何回でも押せますか？
1つの投稿につき、同じ端末・ブラウザからは1回までです(もう一度押すと取り消せます)。グッド済みかどうかはお使いのブラウザに記録されるため、別の端末やブラウザからは別カウントになります。
「バッド」を押すとどうなりますか？
グッドと同じく1端末・1ブラウザにつき1回で、もう一度押せば取り消せます。バッドが一定の数に達した投稿は、利用者の一覧・共有URLから自動的に表示されなくなります(管理者には引き続き見えるので、内容を確認したうえで対応します)。誹謗中傷の代わりではなく、見えにくくしたい投稿の目印として使ってください。
投稿が一覧から消えました。
親作品に紐づけた「子」の投稿や修正依頼の投稿は、既定では一覧に出ません。一覧上部の「子も全て表示」「修正依頼作品も表示」を押すと表示されます。また、バッドが規定数に達した投稿は自動的に非表示になります。それでも見つからない場合は、管理者が削除した可能性があります。
共有URLを送ったのに、相手の画面で作品が開きません。
その投稿が削除されている場合や、URLが途中で切れている場合に起こります。詳細画面の「共有」ボタンで取得したURLをそのまま貼り付けて送ってください。
読み込みが遅い・画像が表示されないことがあります。
投稿データと画像はGoogleのサービスから取得しているため、混み合っている時間帯や通信環境によって時間がかかることがあります。しばらく待つか、ページを再読み込みしてください。何度も失敗する場合は連絡フォームからお知らせください。
投稿してはいけない内容はありますか？
画像はすべてGoogleドライブに保存されるため、Googleの規約に触れる画像が投稿されるとアカウントごと停止され、このサイト自体が終了します。他人の個人情報や、明らかに問題のある画像は投稿しないでください。気になる投稿を見つけたら、連絡フォームから管理者へお知らせください。

管理者へ連絡する

削除依頼・不具合の報告・ご要望などを管理者へ送れます。返信はできませんので、連絡先が必要な場合は本文に記載してください(任意)。

準備するもの

Windowsパソコン(できればNVIDIA GeForceのグラフィックボード搭載機)。VRAM 8GB以上あると快適。空き容量は数十GB単位で余裕を見ておく。画像生成は自分のパソコンの中だけで完結するので、アカウント登録や課金は不要。

STEP 1. Stability Matrix を用意する

1
「Stability Matrix」という無料アプリを使うと、画像生成用のソフト(Forge Neoなど)やモデルをまとめて管理できて楽。公式サイト(https://lykos.ai/)、またはGitHubの配布ページ(https://github.com/LykosAI/StabilityMatrix/releases)から StabilityMatrix-win-x64.zip のようなWindows用ファイルをダウンロードする。
2
ダウンロードしたzipを右クリック→「すべて展開」で解凍し、出てきたフォルダを好きな場所に置く。
注意: 置き場所のフォルダ名・パスに日本語やスペースを含めないこと(例: C:\SDtools のような英数字のみのシンプルな場所)。日本語パスが原因のエラーが非常に多い。
3
中にある StabilityMatrix.exe をダブルクリックして起動。グラフィックボードのスペックチェックで問題がなければ、利用規約に同意して先へ進む。「Portableモード」のチェックは基本つけたままでOK。

STEP 2. Forge Neo をインストールする

1
Stability Matrix内でインストールするパッケージの一覧から 「Stable Diffusion WebUI Forge - Neo」 を選んでインストールする。これが現在の主流バージョンで、古い「Forge」や「Automatic1111」は更新が止まっているため、これから始めるなら基本的にForge Neoを選べば間違いない。
2
かなり大きなファイルを大量にダウンロードするので、セットアップ完了までそこそこ時間がかかる。待っている間にSTEP3のモデル探しを進めておくとよい。

STEP 3. モデル(Checkpoint)をダウンロードして配置する

1
「モデル(Checkpoint)」は絵柄の元になるファイルで、これがないと画像生成はできない。モデルは主にCivitai(https://civitai.com/)というサイトで配布されており、会員登録なしでもダウンロードできる。特にこだわりがなければ、現在ローカル環境で主流のSDXL系のモデル、またはその後継として注目されているAnima系のモデルのどちらかを選ぶのが無難。
初心者向けの定番として、SDXL系なら「WAI-illustrious-SDXL」系統(Civitai: https://civitai.com/models/827184)、Anima系なら「WAI-Anima」系統(Civitai: https://civitai.com/models/2544636)がよく挙げられる。よく分からなければ、それぞれの最新バージョンをダウンロードすればOK。
2
ダウンロードしたモデルファイルは、Stability Matrixをインストールしたフォルダの中の Data → Models → StableDiffusion フォルダに入れる。
注意(Anima系を選んだ場合): Anima系はCheckpoint本体だけでなく、テキストエンコーダーやVAEなど別途用意が必要なファイルがある場合がある。モデルの配布ページの説明をよく読み、指示された追加ファイルも忘れずにダウンロードして、それぞれ対応するフォルダに配置すること。

STEP 4. Forge Neo を起動する

1
Stability Matrix側でForge Neoの「Launch」ボタンを押すと、少し待ってからブラウザで画像生成用の画面(WebUI)が自動で開く。
重要: Stability MatrixとブラウザのWebUIは「本体とテレビ画面」のような関係。ブラウザにWebUIが表示されても、裏側で処理をしているのはStability Matrixなので、WebUIを使っている間はStability Matrixのウィンドウを閉じないこと。閉じると生成が止まってしまう。
初回起動時はPyTorchなど追加の部品を裏側でダウンロード・準備するため、ブラウザ画面が開くまで、また最初の1枚目の画像が生成されるまでにも数分〜十数分かかることがある。フリーズしたように見えても、進行状況(ログ)が動いていれば待っていればOK。

STEP 5. はじめての画像生成

1
画面上部の「Checkpoint」欄で、STEP3で配置したモデルを選択する。もし一覧に出てこない場合は、モデル一覧の更新ボタンを押すか、WebUIを再読み込みしてみる。
2
「Prompt(プロンプト)」欄に描きたいものを表す単語を入力し、生成ボタンを押すだけで画像ができあがる。うまくいかない絵柄は「Negative prompt(除外したい要素)」欄に入れると避けやすくなる。

初心者が特につまずきやすい点(Checkpoint / LoRA まわり)

Checkpointと「土台」が合わないと絵が崩れる。
LoRA(追加の絵柄・キャラクター用の小さな学習データ)は、使っているCheckpointの「土台となるアーキテクチャ」(SDXL系かAnima系かなど)に対応したものを選ぶ必要がある。SDXL用のLoRAをAnima系のCheckpointに使う、といった組み合わせは基本的に噛み合わず、絵が崩れたり全く効かなかったりする。LoRAをダウンロードするときは、対応アーキテクチャの表記を必ず確認する。
ファイルを置いただけでは一覧に出てこないことがある。
LoRAもCheckpoint同様、Data → Models フォルダ内の該当フォルダ(LoRAなら「Lora」フォルダなど)に置く。置いた直後はWebUI側の一覧に反映されていないことがあるので、モデル一覧の更新ボタンを押すか、WebUIを再読み込みして反映させる。
迷ったら「新しいCheckpoint」から。
古い「Forge」や「Automatic1111」向けの解説記事もネット上には多く残っているが、これから新しく始める場合はForge Neoのような現行バージョンを使い、そこに対応したCheckpoint・LoRAで揃えるのが無難。
Anima系はプロンプトの書き方のクセが違う。
SDXL系のプロンプトの感覚のまま使うとうまく効かないことがある。Animaでは、カンマの後に半角スペースを入れる、単語の区切りにアンダースコア(_)を使わない、といった独自のルールがあるとされる。SDXL系からAnima系に乗り換えたときにタグが効かなくなったと感じたら、まずこの書き方の違いを疑うとよい。
生成が極端に遅い・途中で止まる場合はVRAM不足かも。
グラフィックボードのVRAMが少ない環境(8GB未満など)では、そのままの設定だと生成が非常に遅くなったり、エラーで止まったりすることがある。起動オプションに省メモリ向けの設定(低VRAM向けのモード)を追加できる場合があるので、極端に遅い・落ちるときは調べてみるとよい。まずは生成する画像の解像度(Width/Height)を下げてみるのも手軽な対策。
