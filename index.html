    はじめに
    最初の1回だけ、次の準備をします。このページはあなたのPCの ComfyUI とローカルLLMにブラウザから直接つなぐので、画像や設定が外部に送られることはありません。
    
      
      
        
    1. 
          
      ComfyUI に接続を許可する
      
          
      Stability Matrix で ComfyUI のカードの歯車アイコンを開き、一番下の「Extra Launch Arguments」に次の1行をそのまま貼り付けて保存します。
      
          
      
          
      保存したら ComfyUI を一度「停止」してから「Launch」で起動し直します（保存だけでは反映されません）。
      
          
      ポータブル版: run_nvidia_gpu.bat の main.py の後ろ（同じ行）に追記。デスクトップ版: サーバー設定の CORS ヘッダーの項目に  を入力。
      
        
      2. 
        
    2. 
          
      文章AIのサーバーを起動して、CORS をオンにする
      
          
      
            
      Bionic
      設定 →「ローカルモデルAPI」で「ローカルAPIサーバー」と「CORS」をオン
      
            
      LM Studio
      「Developer」でサーバーを起動し、「Enable CORS」をオン
      
            
      Ollama
      環境変数 OLLAMA_ORIGINS に  を設定して起動し直す
      
          
      
        
      3. 
        
    3. 
          
      Chrome か Edge で開く
      
          
      初回に「ローカルネットワーク上のデバイスへのアクセス」の確認が出たら「許可」を押します。
      
        
      4. 
        
    4. 
          
      「文章AI」タブでモデルを選んで保存
      
          
      「自動で探す」を押すと、起動中のサーバーとモデルの一覧が出ます。
      
        
      5. 
        
    5. 
          
      「動画（ComfyUI）」タブで URL を確認して保存
      
          
      MiniMax H3 のワークフローは最初から入っています。別のワークフローを使うときだけ登録します。
      
        
      6. 
      
    
      
    
        
    接続を確認する
    
        
    準備ができたら押してください。両方 🟢 になれば完了です。
    
        
        
    
      
    
    
    

    
    
      
    動画ができるまで
    「実行」を押してから動画が表示されるまでに、裏側で起きていることを順番に並べました。色のついたラベルは「どこで処理されているか」です。どれもあなたのPCの中で行われ、外部のサーバーには送られません。
    
      
      
        
    1. 
          
      ブラウザ画像を読み込む
      
          
      ドロップしたPNGの中に埋め込まれた「メタデータ」を読み取ります。Stable Diffusion で画像を作ったときのプロンプト、ネガティブプロンプト、シード、モデル名などです。この時点では画像はまだどこにも送られていません。
      
        
      2. 
        
    2. 
          
      ブラウザ画像を動画の形に整える
      
          
      「動画のサイズ」の一覧から選んだ縦横比（ComfyUI の解像度セレクターと同じ型）に合わせて、画像を切り抜くか、余白を足します。この画像が動画の最初のフレームになります。動画と画像の縦横比がずれていると、動画モデルが画像を引き伸ばしたり、端が欠けたりする原因になります。
      
        
      3. 
        
    3. 
          
      文章AI動画用のプロンプトを書いてもらう
      
          
      「プロンプト形式」（書き方のルール）、「スキル」（追加の指示）、「プロンプトの指定」（モード・BGM・声・動き）、メタデータ、整えた画像（画像対応モデルのとき。FL2VA なら最後の画像も）をまとめて文章AIに渡し、英語のプロンプトを書いてもらいます。SDのプロンプトは単語の羅列ですが、動画モデルには「何が、どう動き、どんな音がするか」を文章で伝えたほうがうまく動きます。
      
        
      4. 
        
    4. 
          
      文章AI日本語訳を作る（設定でONのとき）
      
          
      確認しやすいように、できた英語プロンプトを日本語に訳します。動画に使われるのは英語のほうです。
      
        
      5. 
        
    5. 
          
      ComfyUI整えた画像を ComfyUI に送る
      
          
      手順2で作った画像を ComfyUI の input フォルダに保存します。
      
        
      6. 
        
    6. 
          
      ブラウザワークフローに値を書き込む
      
          
      登録したワークフロー（JSON）のコピーに、プロンプト・画像のファイル名・シード・動画の長さ・縦横比とメガピクセル（解像度セレクターがない場合は幅と高さ）を書き込みます。L2VA のときは画像を「最後のフレーム」の入力につなぎ替え、FL2VA のときは最後の画像を読み込むノードを追加します。登録した元のJSONは書き換わりません。
      
        
      7. 
        
    7. 
          
      ComfyUI順番待ちのあと、動画を生成する
      
          
      ComfyUI がモデルを読み込み、ノイズから少しずつ映像（MiniMax H3 なら音声も）を作っていきます。いちばん時間がかかる手順です。「本数」で2本以上を選ぶと、同じ画像とプロンプトの依頼がその本数だけ ComfyUI の順番待ちに並び、1本ずつ順に作られます（シードは毎回変わるので、違う動きの動画になります）。進み具合は「生成した動画」のパネルに表示されます。
      
        
      8. 
        
    8. 
          
      ComfyUIできた動画を受け取って表示する
      
          
      完成した動画ファイルを ComfyUI の output フォルダから受け取り、「動画」欄にパネルとして並べます。このとき動画ファイルの中に、プロンプト・使ったモデルと LoRA・シード・元画像の情報などを書き込みます（「この動画を保存」で保存したファイルに入っています）。
      
        
      9. 
        
    9. 
          
      ComfyUIGPUメモリを片付ける（設定でONのとき）
      
          
      文章AIと動画モデルが同じGPUを取り合わないように、ComfyUI が使っていたGPUメモリを解放します。
      
        
      10. 
      
    
      
    やり直すときに動く手順
    「AIで修正」は手順3〜4だけ、「このプロンプトで動画を作り直す」は手順5〜9だけをやり直します。画像の読み込みや、文章AIへの依頼をくり返さないので早く終わります。

    動画（ComfyUI）
    動画を作る ComfyUI の接続先とワークフローです。MiniMax H3 は「MiniMax H3（既定）」として最初から入っています。
    
      
    
      
    
        
    1ComfyUI に接続
    
        
    
          
          
        
    
        
      
    
      
    
        
    2ワークフロー
    
        
    ComfyUI で一度ちゃんと動画が作れたワークフローを、メニューの「ワークフロー」→「エクスポート (API)」で書き出して、ここに入れます。
    
        
        
    
        
    
        
    
          
    書き込み先 自動で選ばれます
    
          
    アプリが値を書き込むノードです。自動で選ばれた結果が違うときだけ変更します。
    
          
    
        
    
      
    
      
    
        
    3動画の作り方
    
        
    
          
          
        
    
        
        
    縦横比と大きさは、メイン画面の「動画のサイズ」で選びます。
    
      
    
      
    
    
    

    
    
      
    スキル
    ふだんは MiniMax H3 公式の「h3-prompt-writing」（公式ページ ↗）を元にした既定のスキルが自動で使われるので、ここは触らなくて大丈夫です。自分用のスキルを使いたいときだけ、読み込むか新しく追加してください。追加したスキルはメイン画面にボタンで表示され、ONにすると既定のスキルの代わりに使われます。
    
      
    
      
    
        
    ファイルで読み込む・書き出す
    
        
    Agent Skills 形式（SKILL.md）に対応しています。Bionic などで使っている SKILL.md もそのまま読み込めます。

    プロンプト形式
    動画モデルごとの基本の書き方（文章AIへの指示文）です。MiniMax H3 は公式ガイドに沿った既定の形式が使われるので、ふだんは触らなくて大丈夫です。{seconds} は動画の秒数に置き換わります。

    設定の書き出し・読み込み
    
        
    別のブラウザやPCに設定を移すときに使います。書き出したファイルには APIキーも含まれるので、人に渡すときは注意してください。
    
        
    
          
          
        
    
      
    
      
    
        
    キャッシュをすべて削除して初期状態に戻す
    
        
    このブラウザに保存されている Stillmotion のデータをすべて消して、ページを開き直します。元に戻せないので、必要なら先に「設定を書き出す」で保存してください。

    消えないもの
    ComfyUI の output フォルダの動画、保存済みのファイル
